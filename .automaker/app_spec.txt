  <project_name>Nuvio Streaming TV</project_name>

  <overview>
    Nuvio Streaming TV is a cross-platform content streaming application that serves as a centralized hub for streaming content discovery, organization, and playback. The project is built with a Rust SDK core (nuvio-core) that provides native bindings for Kotlin (Android) and Swift (iOS/tvOS) through UniFFI, enabling seamless cross-platform integration. The application is fully compatible with Stremio addons ecosystem, allowing users to discover and stream content from multiple addon sources. It integrates with Trakt.tv for comprehensive user activity tracking including continue watching, watchlists, scrobbling, and personalized catalogs. TMDB (The Movie Database) provides rich metadata, imagery, and content information. The frontend is built with React Native and Expo, supporting mobile phones, tablets, and TV platforms (Android TV, Apple TV) with dedicated TV-optimized components and navigation patterns.
  </overview>
