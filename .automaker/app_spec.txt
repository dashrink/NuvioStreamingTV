  <project_name>Nuvio Streaming TV</project_name>

  <overview>
    Nuvio Streaming TV is a fork of the NuvioStreaming repository, extending it to support Android TV (Google TV) and Apple tvOS platforms in addition to its existing iOS, Android mobile, Android tablet, and iPadOS support. The project is a modern, cross-platform media hub application built with React Native and Expo that provides content streaming capabilities through a flexible addon/plugin ecosystem compatible with the Stremio protocol. The application serves as a media discovery and streaming interface, allowing users to browse, search, and stream media content through user-installed plugins and addons. Key goals include maintaining modular architecture to facilitate upstream sync from the original repository, preserving all existing functionality while adding TV-specific navigation, remote control handling, and optimized UI/UX for the 10-foot viewing experience on living room screens.
  </overview>

  <development_guidelines>
    <guideline>Maintain modular architecture to facilitate syncing with upstream NuvioStreaming repository</guideline>
    <guideline>Use Platform.isTV checks to conditionally apply TV-specific code paths</guideline>
    <guideline>Implement TV navigation using the Focusable component wrapper for all interactive elements</guideline>
    <guideline>Keep TV-specific hooks (useTVMode, useTVEventHandler) isolated and zero-impact on mobile builds</guideline>
    <guideline>Use react-native-tvos variant of React Native for TV support</guideline>
    <guideline>Apply @react-native-tvos/config-tv plugin for TV-specific build configuration</guideline>
    <guideline>Separate TV configuration in app.tv.json while maintaining app.json for mobile</guideline>
    <guideline>Use APP_VARIANT=tv environment variable for TV builds</guideline>
    <guideline>Follow existing TypeScript conventions with strict typing</guideline>
    <guideline>Use MMKV for persistent storage instead of AsyncStorage for performance</guideline>
    <guideline>Implement responsive layouts that adapt to phone, tablet, and TV screen sizes</guideline>
    <guideline>Use FlashList for optimized list rendering on all platforms</guideline>
    <guideline>Apply Hermes JavaScript engine for improved performance</guideline>
    <guideline>Maintain compatibility with Expo managed workflow where possible</guideline>
    <guideline>Use react-native-reanimated for smooth animations across all platforms</guideline>
    <guideline>Implement D-pad navigation support using nextFocus* props on Focusable components</guideline>
    <guideline>Test on physical TV devices to ensure proper focus management and remote control behavior</guideline>
  </development_guidelines>
