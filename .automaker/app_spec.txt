  <project_name>Nuvio Streaming TV</project_name>

  <overview>
    Nuvio Streaming TV is a cross-platform content streaming application that serves as a centralized hub for streaming content discovery, organization, and playback. The project is built with a Rust SDK core (nuvio-core) that provides native bindings for Kotlin (Android) and Swift (iOS/tvOS) through UniFFI, enabling seamless cross-platform integration. The application is fully compatible with Stremio addons ecosystem, allowing users to discover and stream content from multiple addon sources. It integrates with Trakt.tv for comprehensive user activity tracking including continue watching, watchlists, scrobbling, and personalized catalogs. TMDB (The Movie Database) provides rich metadata, imagery, and content information. The frontend is built with React Native and Expo, supporting mobile phones, tablets, and TV platforms (Android TV, Apple TV) with dedicated TV-optimized components and navigation patterns.
  </overview>

  <development_guidelines>
    <guideline>Use UniFFI for all Rust-to-native bindings - ensure all types use named fields (no tuple variants)</guideline>
    <guideline>Follow async/await patterns with Tokio runtime for network operations</guideline>
    <guideline>Implement proper error handling with NuvioError types that can cross FFI boundaries</guideline>
    <guideline>Use serde for JSON serialization with proper derive macros</guideline>
    <guideline>Maintain thread-safe state with Arc&lt;RwLock&lt;&gt;&gt; patterns in services</guideline>
    <guideline>Implement comprehensive unit tests with wiremock for HTTP mocking</guideline>
    <guideline>Use platform-specific components (.tv.tsx suffix) for TV platform differences</guideline>
    <guideline>Follow React Native best practices with FlashList for long lists</guideline>
    <guideline>Implement proper caching with TTL for TMDB and other API responses</guideline>
    <guideline>Use MMKV for fast key-value storage on mobile platforms</guideline>
    <guideline>Maintain type safety with TypeScript in the React Native layer</guideline>
    <guideline>Use ESLint and Prettier for code quality and formatting</guideline>
    <guideline>Implement proper PIN security with Argon2 hashing - never store plaintext</guideline>
    <guideline>Handle offline scenarios with queued operations for Trakt sync</guideline>
  </development_guidelines>
