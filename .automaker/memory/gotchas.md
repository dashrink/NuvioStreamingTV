# gotchas

#### [Gotcha] Rust struct modifications in `profile.rs` require manual regeneration of UniFFI bindings before Swift code can access the new fields. (2026-01-18)
- **Situation:** Adding new settings fields (`ProfilePreferences`) in Rust and immediately attempting to use them in `SettingsViewModel.swift`.
- **Root cause:** Swift bindings are static code generated by `uniffi-bindgen`, not dynamically reflected from the Rust binary.
