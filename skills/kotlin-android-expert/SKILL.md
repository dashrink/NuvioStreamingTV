# Kotlin Android Expert

This skill represents deep proficiency in modern Android ecosystem, with a focus on Kotlin, Jetpack Compose, and building TV-first experiences.

## Core Expertise

### 1. Kotlin Fundamentals
- **Coroutines & Flow**: Expert use of asynchronous programming, handling structured concurrency, and reactive streams.
- **Null Safety**: Strict adherence to Kotlin's type system to eliminate `NullPointerException`.
- **Dsl & Extensions**: Building expressive and idiomatic APIs using Kotlin's advanced features.

### 2. Modern UI (Jetpack Compose)
- **Declarative UI**: Building complex layouts with Compose, optimizing for performance and recomposition.
- **Material 3**: Implementing the latest Design System with dynamic color and modern components.
- **Custom Graphics**: Using DrawScope for custom UI elements and animations.

### 3. Android TV Development
- **Focus Management**: Precise control over focus movement, using `FocusRequester` and `onFocusChanged`.
- **Leanback Support**: Proficiency with the Leanback library for traditional TV UIs when necessary.
- **D-Pad Interaction**: Ensuring seamless navigation using remote controls.
- **Compose for TV**: Utilizing TV-specific components like `TvLazyColumn`, `TvLazyRow`, and `Focusable`.

### 4. Architecture & State
- **MVVM/MVI**: Implementing robust architectural patterns with `ViewModel` and `StateFlow`.
- **Dependency Injection**: Expert use of Hilt or Koin for modular and testable codebases.
- **Repository Pattern**: Clean data separation between local storage, network, and UI.

### 5. Media & Performance
- **ExoPlayer/Media3**: Implementing high-performance video players with support for DASH, HLS, and 4K playback.
- **Performance Profiling**: Using Android Studio Profiler to optimize CPU, Memory, and Battery usage.
- **Kotlin Multiplatform (KMP)**: Understanding shared business logic across platforms.

## Implementation Guidelines
- **Modern Standards**: Only use `View` system when specifically requested or for legacy integration; prioritize Compose.
- **Edge-to-Edge**: Implement immersive layouts that respect system bars and cutouts.
- **Strict Linting**: Follow official Kotlin style guides and Android lint rules.
