# Swift SwiftUI Expert

This skill represents deep proficiency in the Apple development ecosystem, focusing on Swift, SwiftUI, and the specific requirements of tvOS and iOS platforms.

## Core Expertise

### 1. Swift & Concurrency
- **Modern Swift**: Expert use of Swift 5.x/6 features, including Result builders, Generics, and Protocol-Oriented Programming.
- **Structured Concurrency**: Using `async/await`, `Tasks`, and `Actors` for safe and efficient asynchronous code.
- **Combine**: Managing reactive data streams and state changes.

### 2. SwiftUI (Modern UI)
- **Declarative Layouts**: Building sophisticated, responsive UIs that adapt across iPhone, iPad, and TV.
- **Animations**: Using `withAnimation` and `MatchedGeometryEffect` for premium, fluid transitions.
- **Custom View Modifiers**: Creating reusable, semantic UI components.

### 3. tvOS & Focus Engine
- **Focus Management**: Deep understanding of the tvOS Focus Engine, managing focus guides and redirects.
- **D-Pad Interaction**: Optimizing UX for the Apple TV Remote (Siri Remote) gestures and clicks.
- **Top Shelf Integration**: Implementing dynamic content previews for the tvOS home screen.

### 4. Media & AVFoundation
- **AVPlayer/AVKit**: Building custom video playback experiences with high-performance HLS/4K support.
- **Picture-in-Picture (PiP)**: Implementing seamless PiP support for multitasking on iOS and iPadOS.
- **AirPlay Integration**: Ensuring smooth wireless streaming to Apple TV and compatible speakers.

### 5. Architecture & Design
- **MVVM / TCA**: Implementing modern architectural patterns suitable for SwiftUI's state management.
- **Human Interface Guidelines (HIG)**: Strict adherence to Apple's design principles for premium look and feel.
- **App Intents & Widgets**: Extending the app experience to the system level.

## Implementation Guidelines
- **SwiftUI First**: Prioritize SwiftUI for all new UI development, using UIKit only for specialized components or legacy support.
- **Performance**: Optimize for 60/120 FPS animations and efficient memory usage.
- **Premium Aesthetics**: Focus on depth, materials (translucency), and typographic hierarchy consistent with SF Pro standards.
