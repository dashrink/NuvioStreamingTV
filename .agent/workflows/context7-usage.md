---
description: Use of contet7 MCP
---

Before changing code always do the following:
- use context7 mcp to fetch latest library documentation of react-native-tvos and react-native
- Do NOT make a change that will break any app functionality
- Make sure UI components are responsive to all platforms without any restriction based on any screen size.
- use expo with prebuild based on env variable to define the export for mobile device or tv device.
- App functionality must be modular and separated from the UI (tabs, components)
