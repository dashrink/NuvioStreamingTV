## Project Overview

### What is Nuvio Streaming TV?
A cross-platform media hub application built with React Native and Expo that:
- Streams media through Stremio-compatible addon ecosystem
- Supports iOS, Android, tablets, Android TV, and Apple tvOS
- Integrates with Trakt.tv for watch history and library sync
- Uses TMDB for metadata (posters, cast, descriptions)
- Supports Debrid services for premium streams
- Features multi-profile support with PIN protection
- Provides TV-optimized focus-based navigation

### Tech Stack
- React Native (react-native-tvos for TV)
- Expo SDK 54
- TypeScript
- React Navigation 7.x
- React Native Reanimated 4.x
- React Native Video 6.x
- MMKV for storage
- FlashList for optimized lists
