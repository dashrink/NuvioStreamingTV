### 5. Scroll-based Pause/Resume ✅
**Files:** useTrailerPlayback.ts (lines 482-509), constants.ts (lines 124-129)

**Verification:**
- SCROLL_THRESHOLDS defines thresholds as percentages of hero height:
  - PAUSE_THRESHOLD: 0.7 (70% - pause when scrolled past this)
  - RESUME_THRESHOLD: 0.4 (40% - resume when scrolled back above this)
- useDerivedValue worklet runs on UI thread for smooth detection
- `scrollGuardEnabledSV` prevents immediate pause on entry (1 second delay)
- `pausedByScrollSV` tracks whether pause was triggered by scroll
- Hysteresis pattern: pause at 70%, resume at 40% (prevents jitter)
- runOnJS(setTrailerPlaying) bridges UI thread to JS thread

**Code Flow (Pause):**
1. User scrolls down past 70% of hero height
2. useDerivedValue worklet detects scrollY.value > pauseThreshold
3. Conditions: isPlaying=true, !isPausedByScroll, isFocused=true
4. pausedByScrollSV.value = 1
5. runOnJS(setTrailerPlaying)(false) pauses trailer

**Code Flow (Resume):**
1. User scrolls back up above 40% of hero height
2. useDerivedValue worklet detects scrollY.value < resumeThreshold
3. Conditions: isPausedByScroll=true
4. pausedByScrollSV.value = 0
5. runOnJS(setTrailerPlaying)(true) resumes trailer
