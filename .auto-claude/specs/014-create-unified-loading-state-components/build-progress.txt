# Build Progress: Unified Loading State Components
# Spec: 014-create-unified-loading-state-components
# Created: 2026-01-10

## Summary
Standardize loading states across the app by creating a unified loading component system.

## Current Status: Phase 2 In Progress (6/6 subtasks complete for Phase 2)

## Problem Statement
Currently there is inconsistent usage of loading states:
- ActivityIndicator used directly in 30+ files
- LoadingSpinner (Lottie-based) with sizes small/medium/large
- DogLoadingSpinner (duplicate Lottie variant)
- TraktLoadingSpinner (branded pulsing animation)
- SkeletonLoaders (shimmer-based for home screen)
- MetadataLoadingScreen (comprehensive shimmer skeleton)
- LoadingOverlay (player loading state)

## Solution
Create unified loading component system:
1. UnifiedSpinner - theme-aware spinner replacing ActivityIndicator
2. ShimmerSkeleton - reusable shimmer skeleton component
3. SkeletonGroup - synchronized skeleton animations
4. LoadingOverlayScreen - full-screen loading overlay
5. ContentSkeleton - preset skeletons for common content types

- Estimated effort: 2-3 days
