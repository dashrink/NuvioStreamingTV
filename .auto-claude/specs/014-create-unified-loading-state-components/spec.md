# Create Unified Loading State Components

## Overview

Standardize loading states across the app by creating a unified loading component system. Currently there's inconsistent usage of ActivityIndicator, LoadingSpinner (Lottie), skeleton loaders, and TraktLoadingSpinner.

## Rationale

Inconsistent loading states create a disjointed user experience. Users see different loading indicators on different screens, making the app feel unpolished. A unified system improves perceived quality and predictability.
