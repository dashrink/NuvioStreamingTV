## Overview
Create a reusable EmptyState component with consistent styling and actionable CTAs to replace ad-hoc implementations across multiple screens.

## Current State Analysis

### Empty States Found (7 screens):
1. **PluginsScreen** - Custom empty state with icon, title, description
2. **SearchScreen** - Two states: "Keep typing..." and "No results found"
3. **HomeScreen** - "No content available" with "Add Catalogs" CTA
4. **LibraryScreen** - Multiple states for Trakt collections and main library
5. **DownloadsScreen** - EmptyDownloadsState component with icon, title, CTA
6. **CalendarScreen** - Empty state for calendar episodes
7. **AddonsScreen** - Empty states for addons

### Issues Identified:
- Inconsistent icon sizes (48-80px across screens)
- Varying CTA button styles and border-radius
- Some hardcoded colors instead of theme colors
- Inconsistent padding/margins
- Duplicate style definitions
