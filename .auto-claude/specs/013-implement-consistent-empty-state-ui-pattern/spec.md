# Implement Consistent Empty State UI Pattern

## Overview

Create a reusable EmptyState component with consistent styling and actionable CTAs. Currently empty states are implemented ad-hoc with varying styles across PluginsScreen, SearchScreen, HomeScreen, and LibraryScreen.

## Rationale

Empty states are critical UX moments that guide users on what to do next. Inconsistent empty states confuse users and miss opportunities to drive engagement. A well-designed empty state can convert a dead-end into an action.
